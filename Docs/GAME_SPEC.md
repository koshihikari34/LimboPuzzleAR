# ゲーム仕様書：LimboPuzzleAR

## 1. 概要

- ジャンル: ARバランスパズル + だるまさんがころんだ
- プラットフォーム: iOS
- 目的: 制限時間内に、目標の高さまで石を積んだセット数を競う
- コア体験: 石を崩さず積む物理パズルと、鬼の監視中に指を離せない緊張感

## 2. ゲームルール

### セットクリア

次の条件をすべて満たした状態が連続0.5秒続くと、1セットクリアとする。

1. プレイヤーが石を掴んでいない。
2. いずれかの石のCollider上端がクリアガイドの高さ以上にある。
3. 配置済みのすべての石の速度と角速度が安定判定の閾値以下である。

条件から外れた場合、1秒の安定時間をリセットする。クリア後は対象の石を発光させ、パーティクルとともに消去し、スコアを1加算する。

### アウト

- 鬼が `Watching` の間に、掴んでいる石から指を離した瞬間にアウトとする。
- `Watching` 中も、石を掴んだまま移動することはできる。
- タッチキャンセルやアプリ中断によって保持を継続できなくなった場合も、石を物理状態へ戻す。アウト判定の扱いは実装時に明示的にテストする。

### スコア

- スコアはクリアしたセット数。
- 制限時間が0になった時点でゲームを終了する。
- 最高スコアは端末へ保存する。

## 3. ゲームフロー

### Title

- 起動直後はタイトルロゴと `TAP SCREEN` を表示する。
- `TAP SCREEN` はゆるく点滅し、画面タップでメニュー表示へ遷移する。
- タップ後に最高スコア、`START`、`EXIT` を表示する。
- `START` ボタンでMainシーンへ遷移する。
- `EXIT` ボタンでアプリを終了する。Editor確認時はPlayを停止する。
- タイトルロゴには、シアン、マゼンタ、`#2FFF00` を使った短いグリッチ演出を間欠的に表示する。

### Main: 設置フェーズ

- 初回起動時はチュートリアルガイドを表示する。
- 2回目以降は画面左下のヘルプボタンからチュートリアルガイドを再表示できる。
- チュートリアルガイド表示中はゲーム進行を一時停止する。
- AR平面を検知する。
- ユーザーが平面をタップしてプレイエリアを確定する。
- 確定位置へ土台、クリアガイド、鬼を生成する。
- 設置完了後にゲームを開始する。

### Main: ゲームフェーズ

- 制限時間のカウントダウンを開始する。
- プレイヤーはNextStoneボタンから石を取得し、AR空間へ配置する。
- 鬼は状態を変化させ、石を離せるタイミングを制限する。
- セットクリア後は次のセットを開始する。
- クリア数に応じて、ガイド高さと鬼の監視頻度が段階的に上がる。

### Main: リザルトフェーズ

- 石の取得と操作を停止する。
- 最終スコアと最高スコア更新を表示する。
- `TITLE` ボタンでTitleシーンへ戻る。

## 4. 石の供給と操作

### 石の供給

- 画面右上のNextStoneボタンから次の石を取得する。
- UIを押し続けるとAR空間に石を生成し、そのまま掴んだ状態にする。
- 同時に掴める石は1個とする。
- 離した石が安定判定の閾値以下になるまで、次の石を取得できない。
- アウト中、ゲーム開始前、タイムアップ後、安定待ち中はNextStoneボタンを無効化する。
- 次の石のサムネイルは、現在選ばれている石種の透明PNGをNextStoneボタンへ表示する。
- 石はBrokenVectorのLowPolyRockPackから選んだ候補をゲーム用Prefab化して使用する。現時点の候補は `Rock Type2 03`、`Rock Type4 01`、`Rock Type6 04`、`Rock Type3 04`。

### 石の移動

初期プロトタイプでは、土台を通りカメラに平行な垂直操作面を使う2.5D方式とする。

- 指の左右移動で石を左右へ動かす。
- 指の上下移動で石の高さを変える。
- 奥行きは土台付近へ固定する。
- 最低位置は土台の高さとする。
- 初期生成位置は「現在の石の最高点 + 石1個分」と「クリアガイドより少し上」の高い方を基準とする。
- 掴んでいる間は `Rigidbody.isKinematic = true` とする。
- 指を離したら `Rigidbody.isKinematic = false` とし、物理演算へ戻す。

## 5. 鬼の状態

鬼は固定位置を基本とし、C#のステートマシンで次の状態を遷移する。

| 状態 | 内容 |
| --- | --- |
| `Safe` | 背中を向けている。石を安全に離せる。 |
| `Warning` | 振り返る予兆。音と動きで警告する。 |
| `Watching` | プレイヤーを見ている。石を離すとアウト。 |
| `Attack` | 石の塔へ突進し、積んだ石を破壊する。 |

### 鬼の仮モデルとアニメーション

- 仮モデルとしてスケルトンモデルを使用する。
- 既存の `OniMarker` は非表示にし、モデルを `OniArea` 配下に配置する。
- `OniVisualView` が `OniState` を購読し、モデルの向きと仮Animator Controllerを切り替える。
- `Idle` / `Safe` は背中向き、`Watching` / `Attack` は正面向き、`Warning` は予兆として中間方向を向く。
- 現在の仮割り当ては、`Warning` が `scream`、`Attack` が `slash01`、それ以外は `idle` とする。
- 攻撃時の突進移動、帰還、破壊演出との同期は今後調整する。

### Attack処理

- 攻撃中は石の取得と操作を禁止する。
- 攻撃演出開始後、少し遅らせて配置済みの石へ衝撃を与える。
- 石が存在しない場合でも攻撃シーケンスは破綻させない。
- 攻撃演出後、残った石と残骸をすべて消去する。
- 鬼が元の位置へ戻って `Safe` になったら操作を再開する。
- 攻撃中も制限時間を進め、攻撃時間をペナルティとする。

## 6. UIと演出

- `Safe`: 「積め！」
- `Warning`: 「来るぞ…」
- `Watching`: 「離すな！」
- `Attack`: アウト演出
- 状態に応じて警告テキスト、LeftStatusの色、StatusIconのSpriteを切り替える。
- LeftStatusの色は、`Idle` = `D9D9D9`、`Safe` = `2FFF00`、`Warning` = `FBFF00`、`Watching` / `Attack` = `FF2200` とする。
- StatusIconのSpriteは、`Idle`、`Safe`、`Warning`、`Watching`、`Out` を使用する。
- クリアガイドは土台から一定の高さに半透明で表示する。
- クリアガイドは棒状表示を非表示にし、土台上の到達高さを示す半透明リング/枠として表示する。
- クリアガイドの高さ更新時は、到達目標が上がったことを伝える短い跳ね演出を行う。
- セットクリア時は石を発光させ、パーティクルとともに消去する。
- セットクリア判定後はリリース済み石を一時的に `isKinematic = true` にして積み状態を固定し、演出中に崩れないようにする。
- セットクリア時の石発光は `MaterialPropertyBlock` で色とEmissionを一時的に上書きし、Material複製を避ける。
- セットクリア用ParticleSystem Prefabを任意指定できる。未指定時は軽量なデフォルトパーティクルを生成して使用する。

### チュートリアルガイド

- 初回起動時にページ式モーダルで表示する。
- 2回目以降は画面左下の `?` ボタンから再表示する。
- 画像と短い説明文で、平面設置、石操作、安定待ち、鬼の監視、スコア加算、アウト時の挙動を説明する。
- ヘルプ/チュートリアル表示中は `Time.timeScale = 0` とし、ゲームタイマー、開始カウントダウン、鬼ステート、鬼の回転、Animator、物理進行を停止する。
- チュートリアル画像は `TutorialGuideView` の `illustrationSprites` でページ順に指定する。
- 平面検知の説明画像は `Photo.unity` と `LimboPuzzleAR/Capture Tutorial Plane` Editorメニューで透明背景PNGとして撮影できる。

## 7. アーキテクチャ

- Feature-BasedなMVVMを基本とする。
- DIはVContainer、通知とタイマー処理はR3を使用する。
- 鬼の状態は1か所で管理し、ViewとUIへ通知する。
- Unity Behaviorは使用しない。
- AR入力、物理、保存などのUnity依存処理と、ゲームルールを分離する。
- 詳細は `Docs/ARCHITECTURE.md` を参照する。

想定する構成:

```text
Assets/LimboPuzzleAR/Scripts/
├── Common/
│   └── Persistence/
├── Title/
│   ├── Models/
│   ├── Views/
│   └── ViewModels/
└── Main/
    ├── Models/
    ├── Views/
    ├── ViewModels/
    ├── Services/
    └── Scopes/
```

## 8. 暫定調整値

以下はInspectorまたは設定アセットから変更可能にし、プレイテストで確定する。

| 項目 | 初期値 |
| --- | ---: |
| 制限時間 | 60秒 |
| クリアガイドの初期高さ | 土台から0.14m |
| クリアごとのガイド上昇量 | 0.02m |
| クリアガイドの上限 | 土台から0.20m |
| 安定継続時間 | 0.5秒 |
| 安定速度閾値 | 0.02m/s |
| 安定角速度閾値 | 2deg/s |
| 残骸の消去時間 | 攻撃演出終了時 |
| Safe時間 | 3.0秒からクリアごとに0.2秒短縮、下限1.8秒 |
| Watching時間 | 2.0秒からクリアごとに0.1秒延長、上限3.0秒 |
