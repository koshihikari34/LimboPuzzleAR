# LimboPuzzleAR

石を崩さず積む物理パズルと、鬼が見ている間は石を離せない緊張感を組み合わせたiOS向けARゲームです。

AR空間に土台を置き、制限時間内に石を積み上げてスコアを伸ばします。単に高く積むだけでなく、鬼の視線や攻撃タイミングを意識しながら「いつ離すか」を判断する、短時間プレイ向けの緊張感を重視しています。

## Features

- AR平面検知によるプレイエリア設置
- 石のプレビュー、配置、物理挙動を使った積み上げパズル
- 鬼の状態に応じた緊張感のある入力制約
- セットクリア、スコア、ハイスコア保存
- 初回チュートリアルとヘルプ表示
- タイトル演出、リザルト表示、シーン遷移演出

## How to Play

1. iOS実機でAR平面を検出し、土台を配置します。
2. 表示された石を土台の上へ積みます。
3. 鬼が見ている間は、指を離さないように耐えます。
4. 目標高さまで積むとセットクリアとなり、スコアが加算されます。
5. 制限時間終了後、リザルトでスコアとハイスコアを確認します。

## Tech Stack

- Unity `6000.3.13f1`
- AR Foundation `6.3.4`
- Universal Render Pipeline
- VContainer `1.18.0`
- R3 `1.3.0`
- uGUI / TextMeshPro

## Architecture Highlights

- Feature-BasedなMVVM構成
- ViewModelは具体的なViewを参照せず、R3で状態とイベントを公開
- ViewはUnityオブジェクト、UI表示、物理挙動との橋渡しを担当
- AR、保存、時刻などの外部境界はServiceとして分離
- 鬼のAIは外部Behaviorツールを使わず、C#の明示的なステートマシンで実装
- Editor確認用Serviceと実機AR用Serviceを分け、AR依存部分とゲームロジックを分離
