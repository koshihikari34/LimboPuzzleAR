# LimboPuzzleAR

石を崩さず積む物理パズルと、鬼が見ている間は石を離せない緊張感を組み合わせたiOS向けARゲームです。

## 開発環境

- Unity `6000.3.13f1`
- AR Foundation `6.3.4`
- VContainer `1.18.0`
- R3 `1.3.0`
- Universal Render Pipeline
